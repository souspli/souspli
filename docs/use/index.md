## The five-minute tour

1. **Install and open it.** On first run Souspli creates an identity — a key that
   lives on your machine. There is no sign-up because there is nobody to sign up with.
2. **Press New → Memo.** Fill it in under *Edit*, flip to *View* to see exactly what
   will be signed, press **Publish**, and confirm. You now hold a signed letter.
3. **Press Share… → Save as file…** and send the `.thing` file to a friend by any
   means you like. They double-click it; Souspli verifies the signature and every
   attachment before showing a pixel, and tells them who signed it.
4. **They press Comment**, write a reply, and send *that* file back. Your copy of
   the memo now shows a comment under it — a thread, with no server in between.

Everything else — forums, contracts, votes, moderation — is that same loop with
different types of letter.
