# Souspli

**Signed, self-contained letters that people send each other and keep — instead of
pages a server renders for them.**

A Souspli letter is one file. It carries its own content, images, layout and
behaviour, and its author's signature covers all of it. You open it in a sealed
container that has no network, so it can be as interactive as a web page and still
cannot report on you. You can hand it on by any channel — a file, a paste, a
torrent, a relay — and whoever receives it can verify it without asking anyone.

Out of that one object you can build the things people use servers for: an article,
an invitation, an invoice, a contract with four signatures, a club with a roster, a
forum with threads, votes and moderation. No accounts, no host, nothing to shut down.

> **Status: experimental alpha.** It works, it is tested hard, and it is not yet
> something to trust with anything valuable. [What is and is not there](use/status.md).
